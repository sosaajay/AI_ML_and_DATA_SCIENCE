HOLISTIC DATA PREPARER — PROJECT EXPLANATION (Video Script Notes)
=====================================================================

---------------------------------------------------------------------
1) PROJECT KYA HAI (Overview)
---------------------------------------------------------------------
- Project ka naam hai "Holistic Data Preparer".
- Isme ek raw (messy) customer credit risk dataset liya gaya hai aur
  use step-by-step clean karke, Machine Learning model ke liye
  "ready" bana diya gaya hai.
- "Holistic" isliye bola gaya kyunki isme data preparation ki almost
  har important technique cover ki gayi hai — sirf ek-do nahi.
- Final output: ek fully numeric, 0 missing-value wala dataset jise
  seedha kisi ML model (jaise loan default prediction model) mein
  daala ja sakta hai.

---------------------------------------------------------------------
2) DATASET KAHA SE AAYA (3 Sources)
---------------------------------------------------------------------
- customer_credit_risk.csv  -> main customer data (CSV file se)
- customer_metadata.json    -> extra info (JSON file se)
- loan_history.db           -> loan payment history (SQLite database se)
- Bonus: ek live World Bank API se bhi India ka inflation data fetch
  kiya gaya hai, taaki dikhaya ja sake ki data sirf files se nahi,
  internet se bhi liya ja sakta hai. Agar internet na ho to code
  crash nahi hota — ek "dummy fallback" value use ho jaati hai.

---------------------------------------------------------------------
3) NOTEBOOK KA STRUCTURE (Part A se Part H tak)
---------------------------------------------------------------------

PART A — Theory Questions
  - Data Analysis kya hota hai, Data Science project kaise plan karte
    hain, ML problem ko kaise "frame" karte hain — yeh sab short mein
    explain kiya gaya hai.
  - Tensors (Scalar, Vector, Matrix, 3D Tensor) ko NumPy examples ke
    saath dikhaya gaya hai — yeh ML/Deep Learning ka basic building
    block hai.

PART B — Data Acquisition (Data laana)
  - Data ko 4 alag sources se load kiya: CSV, JSON, SQL Database, aur
    live API.
  - Yeh dikhata hai ki real projects mein data ek jagah se nahi,
    multiple jagah se aata hai.

PART C — Data Understanding & Cleaning
  - df.info(), df.describe(), df.isnull().sum() se dataset ko samjha
    gaya — kitne columns hain, kaunse numeric/categorical hain, kahan
    kahan values missing hain.
  - "ydata-profiling" library se ek automatic HTML report banayi gayi
    (data_quality_report.html) jisme har column ki puri detail hai.

PART D — Missing Value Handling (7 techniques try kiye)
  1. Complete Case Analysis — jis row mein missing value hai use hata do
     (sabse simple, but data loss ka risk).
  2. Mean Imputation — numeric column ke missing values ko us column
     ke average se bhar do.
  3. Most Frequent Imputation — categorical column (jaise gender) ke
     missing values ko sabse common value se bhar do.
  4. Random Sample Imputation — missing value ko usi column ki kisi
     real value se randomly bhar do.
  5. KNN Imputation — sabse similar rows dekh kar unka average lo.
  6. MICE Imputation — sabse advanced, baar baar predict karke value
     ko refine karta hai.
  -> FINAL PROJECT MEIN CHOSEN METHOD: Mean (numeric ke liye) +
     Most Frequent (categorical ke liye) — kyunki missing values
     zyada nahi the aur data ka distribution stable tha.

PART E — Outlier Handling (4 techniques try kiye)
  1. Z-Score Method — jo value mean se 3 standard deviation se zyada
     door hai, use outlier maana.
  2. IQR Method — boxplot wala classic rule (Q1-1.5*IQR se Q3+1.5*IQR
     ke bahar wali values outlier).
  3. Percentile Method — 1st aur 99th percentile ke bahar ki values
     ko clip kar do.
  4. Winsorization — extreme values ko ek percentile par "cap" kar do,
     bina kisi row ko delete kiye.
  -> FINAL PROJECT MEIN CHOSEN METHOD: Winsorization — annual_income,
     loan_amount, aur credit_score teeno columns par apply kiya, kyunki
     isse rows delete nahi hote aur extreme values ka asar bhi kam ho
     jaata hai.

PART F — Encoding & Feature Engineering
  - Label Encoding: gender jaise binary column ko 0/1 me convert kiya.
  - Ordinal Encoding: education_level jaisa "ordered" column (Primary <
    Secondary < Graduate < Post-Graduate) ko unke order ke hisaab se
    numbers diye.
  - One-Hot Encoding: region aur loan_purpose jaise "no natural order"
    wale columns ke liye alag-alag 0/1 columns banaye.
  - Date columns ko todkar Year, Month, Day, Weekday nikala.
  - Binning/Binarization/K-Means clustering se numeric columns ko bhi
    naye tarike se group kiya.

PART G — Feature Scaling
  - StandardScaler — mean 0, standard deviation 1 (sabse common,
    isliye final scaled dataset ke liye yahi chosen hai).
  - MinMaxScaler — sab values ko 0 se 1 ke range mein le aata hai.
  - MaxAbsScaler — maximum absolute value se divide karta hai.
  - RobustScaler — outliers se kam affect hota hai (median/IQR use
    karta hai).

PART H (Transformations wala part, notebook mein "Part G" naam se) —
  - Log, Square Root, Reciprocal, Box-Cox, Yeo-Johnson transformations
    try kiye — inka kaam hai skewed (tedhe-medhe) numeric columns ko
    zyada "normal/symmetric" shape dena.
  - Naye engineered features banaye:
      * Debt-to-Income Ratio = loan_amount / annual_income
      * Spending-to-Income Ratio
      * Average Monthly Transactions

PART H (Final Export) — Sabse important part!
  - Yahan tak jo bhi Parts C-G mein alag-alag test kiya tha, wo sirf
    "demo/comparison" ke liye tha — har baar df.copy() use hota tha,
    matlab original data change nahi hota tha.
  - Is final part mein, sabse best method har step ke liye choose
    karke, EK hi dataset (final_df) par step-by-step sabko apply kiya:
      1) Missing values fill kiye (mean + most frequent)
      2) Outliers winsorize kiye (3 columns par)
      3) Categorical columns encode kiye (label + ordinal + one-hot)
      4) Date ko Year/Month/Day/Weekday mein toda
      5) Binning, binarization, aur K-Means clustering apply kiya
      6) Skewed columns ko log aur Yeo-Johnson se transform kiya
      7) Naye ratio features banaye (debt-to-income, spending ratio,
         avg monthly transactions)
      8) Final dataset export kiya -> final_cleaned_dataset.csv
      9) Usi dataset ko StandardScaler se scale karke ek aur file
         banayi -> scaled_dataset.csv
